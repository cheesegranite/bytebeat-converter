# bytebeat-converter
converts audio into bytebeat using a custom encoding thingy because raw samples are boring.

the converter turns audio samples into bytebeat that can reconstruct the audio during playback.

the bytebeat reconstructs the audio using my custom function, which i call **fbvlve**:
```js
fbvlve=(data,a,t)=>a+(data[0][data[1][t]??0]??0)
```

# why use fbvlve?
raw samples are boring and take up a lot of space. fbvlve produces **compressed data**, which makes the generated bytebeat smaller.

the converter also includes a lossy mode which can compress the bytebeat **even more**.

# how to use my converter
1. open a bytebeat composer ([dollchan bytebeat composer](https://dollchan.net/bytebeat/) preferred)
2. paste the bytebeat from `fbvlve-player.js`.
3. keep that tab/window open for later.
4. make sure you have the necessary python packages for `bytebeatconverter.py`.
5. run that python script.
6. enter the file path, target sample rate, and compression level.
7. wait for the encoder to finish encoding.
8. copy the encoded data.
9. replace the fbvlve placeholder with the encoded data.
10. click play i guess

# example bytebeat
the repo includes `example.js`, a pre-generated bytebeat using fbvlve data.

the example sound is **"homer let the barts out"**.

it uses a 4000hz sample rate and is about 203 KB.
